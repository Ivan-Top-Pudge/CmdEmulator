# Демонстрация этапа 2

Сначала выполните `sh tests/stage2.sh`. Скрипт проверяет форматирование,
`go vet`, тесты, сборку, справку и ошибки запуска без открытия окна.

Затем выполните каждый сценарий ниже отдельно; закрывайте окно через `exit`
перед следующим запуском. Итоговые параметры выводятся в терминал, диалог
со стартовым скриптом — в окно эмулятора.

| Запуск | Ожидаемый результат |
| --- | --- |
| `sh scripts/run-cli.sh` | Заголовок `stage2-vfs.xml`, приглашение `cli> `, история изначально пуста |
| `sh scripts/run-json.sh` | Приглашение `student@stage2:$ `, выполнен `scripts/startup.txt` |
| `sh scripts/run-override.sh` | Приглашение `override> `, скрипт из JSON отключён |
| `sh scripts/run-script.sh` | Приглашение `script> `, выполнен скрипт, заданный через CLI |
| `./build/cmd-emulator --vfs testdata/stage2-vfs.xml` | Приглашение по умолчанию `$ `, скрипта нет |
| `./build/cmd-emulator --config configs/default.json --prompt=""` | История выводится без приглашения |

В `scripts/startup.txt` блочный комментарий `/* ... */`, строковый `//`
и пустые строки не попадают в историю. Комментарии могут идти после команды;
в кавычках и при экранировании их маркеры остаются частью аргумента.
При незакрытом `/*` приложение сообщает исходную строку начала блока до создания GUI.
`ls "$HOME"` показывает значение окружения реальной ОС. Ошибки `unknown`,
`ls one two`, `exit extra` содержат номера строк, после них выполняется `cd /`.
Затем поле ввода должно включиться и получить фокус: введите `ls /` вручную.

Проверьте завершение из скрипта:

```bash
./build/cmd-emulator --vfs testdata/stage2-vfs.xml --script tests/data/stage2-exit.txt
```

Окно должно автоматически закрыться; строка `cd /ignored-after-exit` не выполняется.
То же завершение при запуске только с JSON:

```bash
./build/cmd-emulator --config tests/data/exit-config.json
```

Для проверки запуска из исходников:

```bash
go run ./src/cmd/emulator --config configs/default.json
make run ARGS="--config configs/default.json --prompt 'make> '"
```

Проверка путей относительно JSON: запустите исполняемый файл из другого
каталога и передайте абсолютный путь к `configs/default.json`. Файлы VFS
и скрипта должны найтись по путям из JSON независимо от каталога запуска.

Ошибки запуска отдельно проверяются через `sh tests/stage2-errors.sh`.
Ожидается код завершения 1 и сообщение `Ошибка запуска:`; окно не создаётся.

На этапе 2 проверяется доступность физического файла VFS, а XML ещё не
разбирается. Загрузка файлов и каталогов в память относится к этапу 3.
