# Демонстрация этапа 1

Сначала выполните `sh tests/stage1.sh`, затем
`make run ARGS="--vfs testdata/stage2-vfs.xml"`.
Начиная с этапа 2 путь к VFS обязателен; с этапа 3 заголовок содержит имя из XML — `stage2-vfs`.

Вводите команды последовательно. Часть команд выполните по Enter, часть —
кнопкой «Выполнить». После каждой команды поле должно очищаться и сохранять
фокус, а история — показывать команду и результат.

| Ввод | Ожидаемое поведение |
| --- | --- |
| Пустая строка или пробелы | История не меняется |
| `ls` | `ls: аргументы []` |
| `ls /` | `ls: аргументы ["/"]` |
| `cd` | `cd: аргументы []` |
| `cd "my folder"` | `cd: аргументы ["my folder"]` |
| `ls "$HOME"` | Один аргумент со значением `HOME` реальной ОС |
| `ls "${HOME}/sub"` | Значение `HOME` с суффиксом `/sub` |
| `ls '$HOME'` | Буквальный аргумент `$HOME` |
| `ls my\ folder` | Один аргумент `my folder` |
| `unknown` | Сообщение о неизвестной команде |
| `ls one two` | Сообщение о лишних аргументах |
| `cd one two` | Сообщение о лишних аргументах |
| `ls -a` | Сообщение о неподдерживаемых опциях |
| `cd ""` | Сообщение о пустом пути |
| `ls "unfinished` | Сообщение о незакрытой кавычке |
| `ls ${HOME` | Сообщение о незакрытой переменной |
| `exit extra` | Ошибка; окно остаётся открытым |
| `ls /` | После ошибок команды продолжают выполняться |
| `exit` | Окно закрывается и процесс завершается |

Повторите `ls` достаточно раз, чтобы история превысила высоту окна. Последний
результат должен быть виден, а ранние команды — доступны при прокрутке вверх.

На этом этапе `ls` и `cd` показывают только разобранные аргументы: содержимое
каталогов и смена текущего каталога будут реализованы после подключения VFS.
