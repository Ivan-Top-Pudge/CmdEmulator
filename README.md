# CmdEmulator

Эмулятор командной строки UNIX-подобной операционной системы с графическим
интерфейсом на Go и Fyne.

Проект выполняется по варианту №2 практической работы по конфигурационному
управлению.

## Требования

- Go 1.25 или новее;
- системные зависимости Fyne для используемой операционной системы;
- Make.

## Запуск

Запуск приложения из исходного кода:

```bash
make run
```

Для передачи параметров приложения используйте переменную `ARGS`:

```bash
make run ARGS="--config configs/default.json"
```

Прямой запуск без Make:

```bash
go run ./src/cmd/emulator
```

## Сборка

```bash
make build
```

Исполняемый файл будет создан по пути `build/cmd-emulator`.

## Тестирование

```bash
make test
```

## Очистка

Удаление локальных артефактов сборки:

```bash
make clean
```
